Monthly Native turns your Mac desktop into a customizable monthly calendar.

### Install

Download **MonthlyNative.dmg**, open it, drag Monthly Native to Applications, then launch it and click Apply. **macOS 14+** is required. The app includes Apple Silicon and Intel binaries; Intel hardware execution remains unverified. `MonthlyNative.zip` is the same app in an alternative archive. GitHub's source archives are for building, not installing.

**Signing:** this release is ad-hoc signed, not Developer ID signed or notarized. macOS may block the download. If you trust the project, follow [Apple's opening instructions](https://support.apple.com/en-us/102445), or build from source. Do not disable macOS security protections.

### Included

- Custom colours, two-colour gradients, 24 gradient presets and seasonal palettes.
- Three layouts, five vertical rules, date highlighting and optional Calendar events.
- Saved designs with exact daily times or ordered hourly/daily changes.
- In-window Settings and an immediate, persistent desktop-dot toggle.
- Native per-display rendering, PNG export and menu-bar controls.

Closing the window keeps updates running. **Command-Q stops automatic updates.**

The release workflow runs the test suite, renders 111 samples from a standalone app, builds both architectures, and verifies the DMG and bundled signature before uploading. See the repository's validation document for local UI checks and unverified hardware/permission paths. SHA256SUMS.txt contains download checksums.
